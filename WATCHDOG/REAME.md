## What is Watchdog 
Watchdog or Watchdog timer is used to represent the continuous working of the system

## Function
The timeout is set for every system to run specific task ,the timer restarts and starts counting when the task start running and if the output is not generated in time due to errors ,the watchdog timer set microcontroller into restart state which is known state .If the task performs well within specified time then the watchdog timer set into restart state and there is no effect on microcontroller
